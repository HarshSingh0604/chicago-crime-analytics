Task 3 — Generate New Features

Date-derived fields were generated from the cleaned date column.

  • Generated Year for comparison with the original year field.
  • Extracted Month from the date.
  • Extracted DayOfWeek from the date.
  • Extracted Hour for later time-based analysis.
  • Verified that the generated Year values matched the original year values, then retained the original lowercase year column.

Task 4 — NumPy & Missing-Value Analysis

NumPy was used to calculate missing-value percentages for every column.

  • Calculated the percentage of missing values for every column using NumPy.
  • Checked for columns with more than 50% missing values.
  • No columns in the current dataset exceeded the 50% missing-value threshold, so no columns were dropped.

Task 5 — Database Insertion

The cleaned data was inserted into the project's SQLite database, which is the selected implementation for the database layer.

  • Created the crimes table using SQLAlchemy.
  • Defined id as the primary key.
  • Inserted the cleaned data into chicago_crime.db.
  • Existing database records are preserved during normal Use Case 1 reruns.
  • Verified the database contents after insertion.

Crime Table Schema

Schema designed for the crimes table. The id field is the primary key and is automatically managed by the database.

Column Data Type Key / Role Description
id INTEGER PRIMARY KEY Unique identifier for each crime record.
case_number TEXT — Unique police case/reference number.
date DATETIME — Date and time when the crime was reported.
block TEXT — Block/location reference associated with the incident.
iucr_code TEXT — Illinois Uniform Crime Reporting code.
primary_type TEXT — Primary crime category.
description TEXT — Detailed description of the crime.
location_desc TEXT — Description of the location where the incident occurred.
arrest BOOLEAN — Indicates whether an arrest was made.
domestic BOOLEAN — Indicates whether the incident was domestic-related.
beat_num INTEGER — Police beat number.
district_code INTEGER — Police district code.
ward_no INTEGER — Chicago ward number.
community_code INTEGER — Chicago community area code.
fbi_code TEXT — FBI crime classification code.
x_coordinate REAL — X coordinate associated with the location.
y_coordinate REAL — Y coordinate associated with the location.
year INTEGER Derived Year derived from the crime date.
date_of_update DATETIME Derived Timestamp of the most recent database update.
latitude REAL — Latitude coordinate of the incident.
longitude REAL — Longitude coordinate of the incident.
location TEXT — Geographic location representation.
Month INTEGER Derived Month extracted from the crime date.
DayOfWeek TEXT Derived Day of the week extracted from the crime date.
