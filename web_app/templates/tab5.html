Use Case 4 — SQL Reporting & Integration

SQL-based reporting, database views, Pandas integration, and analytical outputs generated from the crimes database.

Task 1 & 2 — Summary Tables & SQL Queries

SQL-based summary tables and analytical queries were created from the central crimes table.

  • Created the summary table crime_summary_yearly for yearly crime and arrest totals.
  • Created the summary table crime_summary_by_category for crime-category counts and percentage contribution.
  • SQL queries were used to calculate crime count per year.
  • SQL queries were used to calculate top crime types and their percentage contribution.
  • SQL queries were used to calculate arrest count per year.
  • The summary tables are generated from the central crimes table and provide the foundation for the database views, visualizations, and reports presented below.

SQL Queries Executed

The following SQL queries were used to generate the required Use Case 4 summaries and analytical results.

1. Crime Count per Year

SELECT
    year,
    COUNT(*) AS crime_count
FROM crimes
GROUP BY year
ORDER BY year;

2. Top 5 Crime Types and Their Percentages

SELECT
    primary_type,
    COUNT(*) AS crime_count,
    ROUND(
        COUNT(*) * 100.0 /
        (SELECT COUNT(*) FROM crimes),
        2
    ) AS percentage
FROM crimes
GROUP BY primary_type
ORDER BY crime_count DESC
LIMIT 5;

3. Arrest Count per Year

SELECT
    year,
    SUM(
        CASE
            WHEN arrest = 1 THEN 1
            ELSE 0
        END
    ) AS arrest_count
FROM crimes
GROUP BY year
ORDER BY year;

Task 3 & 4 — Database Views & Pandas Integration

SQL views were created from the central crime table and integrated with Pandas for further analysis.

  • Created the SQL view vw_crime_yearly for yearly crime and arrest summaries.
  • Created the SQL view vw_crime_by_category for crime-category counts and percentages.
  • Both views were read into Pandas DataFrames using pd.read_sql().
  • The resulting Pandas DataFrames were used as the source for the visualizations and analytical reporting shown below.

Yearly Crimes vs Arrests

Key Insights

  • Total recorded crimes fluctuate across the observed years, with the highest crime count in 2016 at approximately 242 incidents and the lowest in 2017 at approximately 191 incidents.
  • Total arrests remain substantially lower than total crimes throughout the period, ranging from approximately 56 to 75 arrests per year.
  • The highest number of arrests occurs in 2019, with approximately 75 arrests, while the lowest occurs in 2017, with approximately 56 arrests.
  • Crime counts and arrests show similar movement in several years. Both reach their lowest observed levels in 2017, followed by increases through 2018 and 2019.
  • Despite fluctuations in crime volume, arrests remain considerably lower than total recorded crimes in every year, highlighting the difference between reported incidents and incidents resulting in an arrest.
  • The visualization is based on the vw_crime_yearly database view, which was read into Pandas using pd.read_sql() before generating the chart.

Crime Categories by Percentage

Key Insights

  • THEFT represents the largest share of recorded crimes, accounting for approximately 21% of the total.
  • BATTERY is the second-largest category at approximately 16.5%, followed by ASSAULT at around 9.8%.
  • NARCOTICS and BURGLARY contribute similar shares of approximately 9% each, while ROBBERY accounts for slightly more than 8%.
  • MOTOR VEHICLE THEFT and VANDALISM each account for roughly 6% of recorded crimes, considerably less than the leading categories.
  • PUBLIC PEACE VIOLATION and DECEPTIVE PRACTICE have the smallest shares among the ten categories shown, at approximately 4% and 3.5%, respectively.
  • Overall, the distribution is concentrated in a small number of leading categories, with THEFT having the largest individual share.
  • The visualization is based on the vw_crime_by_category database view, which was read into Pandas using pd.read_sql() before generating the chart.
